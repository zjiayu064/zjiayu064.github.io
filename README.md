# Jiayu's Homepage

This repository hosts Jiayu Zhao's personal homepage.

## Where to edit

- Personal information and profile links: `_data/profile.yml`
- Left-side navigation: `_data/navigation.yml`
- Home-page content: `_pages/home.md`
- Publication content: `_pages/publication.md`
- Site-wide colors and dimensions: `_sass/_site-tokens.scss`
- Layout, navigation, profile, content, and responsive styles: the matching
  `_sass/_site-*.scss`, `_sass/_profile-intro.scss`, and `_sass/_content.scss`
- Shared page structure: `_layouts/default.html`
